WHY ON EARTH — Assistant

A personal channel-management and analysis tool operated by the owner of WHY ON EARTH?. The Google Cloud project was originally named Assistant stick man.

What the application does

The assistant uses YouTube APIs to review channel and video metadata, prepare editorial audits and, when explicitly authorized by the channel owner, update titles, descriptions, thumbnails and publication settings. Read-only YouTube Analytics access is planned for performance analysis when enabled and granted.

This application is for the owner's personal use, not a public sign-in service. It runs through scripts in an Arena.ai workspace. This website only provides application information; it does not collect Google passwords or OAuth tokens.
